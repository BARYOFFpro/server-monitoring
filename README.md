# Мониторинг микроклимата серверной

Консольная программа для контроля температуры и влажности в серверной.
Модуль-отправитель опрашивает датчики и передаёт показания в формате JSON,
модуль-получатель проверяет данные, фиксирует выход за допустимые пределы
и формирует отчёт.

## Запуск
    python src/main.py            # обычный режим
    python src/main.py --debug    # с отладочным выводом
    python -m pytest test         # тесты

## Структура
- src/ — исходный код, config/ — пороговые значения, docs/ — отчёты,
  scripts/ — вспомогательные скрипты, lib/ — сторонние библиотеки, test/ — тесты.
